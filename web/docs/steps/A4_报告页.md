# A4 报告页（B站粉 · 8 模块） — 实现步骤

## 1. 功能需求

- 把 A1/A2/A3 的分析结果渲染成一个可读的网页报告
- 8 个模块：① KPI 仪表带 ② 时间轴主图 ③ 高能片段卡片 ④ 反应词标签云
  ⑤ 主题关键词 ⑥ 弹幕类型分布 ⑦ 活跃时段 ⑧ 热门弹幕表
- 输入页：输 BV 号 -> 跳转分析页；分析页顶部可换 BV 号
- 配色：浅色底 + B站粉（用户选定，替代之前嫌丑的蓝色数据密集风）

## 2. 技术选型

- Django 模板（服务端渲染静态部分）+ Bootstrap 5（布局）
- ECharts 5.5（CDN，base.html 已引入）：时间轴/条形/环形/柱状图
- 参考同类项目页面结构：
  - emoekg：顶部 Vital 卡 + 心电图主图 + 转折点卡片（结论先行、主图最大）
  - bili-danmaku-statistic：词云 + 分布 + 可搜索弹幕表
  - B站创作中心：KPI 指标卡 + 弹幕分布曲线
- 路由归属：页面路由放 apps/web（挂 "/"），API 才放 apps/fetcher（挂 "/api/"）

## 3. 实现思路（算法逻辑总览）

```
浏览器 GET /danmaku/analyze/?bvid=XXX
  -> views.danmaku_analyze
  -> data/out/danmaku/{bvid}.json 不存在则现场 analyze_danmaku(bvid)（读库现算）
  -> _segments_for_template(data) 预处理：
       hot_segments_v2 × sentiment.by_segment 合并 -> 每段补 label/label_class/time_str/peak_str
       evidence 补 color_hex（弹幕颜色整数 -> #RRGGBB）
  -> render analyze.html：静态部分模板渲染（KPI/卡片/表格），动态部分 JS + ECharts
```

页面布局（8 模块）：
```
顶部栏（标题/UP主/分区/时长 + 换BV搜索框）
① KPI 6 卡：弹幕总数/参与人数/正面占比/最炸时刻/反应词数/高能片段数
② 时间轴主图（300px，最宽）：柱=密度 + 线=情绪 + markArea 粉色块=高能片段
③ 高能片段卡片（左 60%）：时间/情绪徽章/条数/峰值 + 佐证弹幕 chips（原色圆点）
④ 反应词标签云（右 40%）：尺寸=频次，颜色=情绪（绿正/红负/灰中）
⑤ 主题关键词条形图（横向，粉色渐变）
⑥ 弹幕类型环形图 + ⑦ 活跃时段柱状图
⑧ 热门弹幕表（进度条 + 搜索过滤）
```

## 4. 具体代码实现

### 4.1 views.py —— 视图（读 JSON / 现算 / 预处理）

```python
def danmaku_analyze(request):
    bvid = request.GET.get("bvid", "").strip()
    if not bvid:
        return redirect("/danmaku/")
    path = settings.DATA_ROOT / "out" / "danmaku" / f"{bvid}.json"
    if not path.exists():
        from apps.analytics.analysis.danmaku import analyze_danmaku
        try:
            analyze_danmaku(bvid)          # JSON 不在就从数据库现算
        except ValueError as e:
            raise Http404(str(e))
    data = json.loads(path.read_text(encoding="utf-8"))
    ...
    return render(request, "danmaku/analyze.html", {
        "data": data, "meta": meta,
        "segments": _segments_for_template(data),
        "data_json": json.dumps(data, ensure_ascii=False),   # 给 JS 图表用
    })
```

**讲解**：JSON 缓存在 `data/out/danmaku/`，没有就现算——避免每次刷新都重算。
`data_json` 用 `json.dumps` 转成 JS 对象（`var DATA = {{ data_json|safe }}`）。

### 4.2 _segments_for_template —— 模板预处理

```python
def _segments_for_template(data):
    seg_list = data.get("hot_segments_v2", [])
    by_seg = (data.get("sentiment") or {}).get("by_segment", [])
    label_cls = {"正面": "pos", "负面": "neg", "中性": "neu"}
    result = []
    for i, s in enumerate(seg_list):
        sb = by_seg[i] if i < len(by_seg) else {}
        label = sb.get("label") or "中性"
        result.append({
            **s,
            "label": label,
            "label_class": label_cls.get(label, "neu"),
            "time_str": f"{_mmss(s['start'])} - {_mmss(s['end'])}",
            "peak_str": _mmss(s.get("peak_sec", 0)),
            "evidence": [{**e, "color_hex": f"{int(e.get('color',0)) & 0xFFFFFF:06X}"}
                         for e in s.get("evidence", [])],
        })
    return result
```

**讲解**：Django 模板**不能动态索引列表**（如 `data.sentiment.by_segment[i]`），
所以在视图里把 `hot_segments_v2` 和 `sentiment.by_segment` 按位置合并成一个列表，
补上情绪徽章 class、`mm:ss` 时间字符串、弹幕颜色十六进制（页面画原色小圆点）。

### 4.3 analyze.html —— 时间轴主图（ECharts）

```js
var density = tl.values.map(function(v,i){ return [i*w + w/2, v]; });   // [桶中心秒, 条数]
var emo = [];
sent.score.forEach(function(v,i){
  if(v!==null) emo.push({value:[i*w+w/2, v], itemStyle:{color: v>=0 ? '#1FA05C' : '#E5484D'}});
});
var markData = segs.map(function(s){ return [{xAxis:s.start, itemStyle:{color:'rgba(251,114,153,.16)'}}, {xAxis:s.end}]; });
series: [
  {name:'弹幕密度', type:'bar', data:density, barWidth:'62%', yAxisIndex:0},
  {name:'情绪', type:'line', data:emo, yAxisIndex:1, smooth:true,
   markArea:{silent:true, data:markData}}
]
```

**讲解**：
- x 轴用**数值秒**（`type:'value'`），每个点 `[桶中心秒, 值]`，比字符串分类轴更利于 markArea 定位
- 双 y 轴：左=密度（柱），右=情绪（线，-1~1），情绪点按正负单独着色
- 高能片段用 `markArea` 画半透明粉色块，一眼看到高潮位置

## 7. 踩坑记录

1. **页面路由误挂在 api 下**：旧 fetcher/urls.py 把 `danmaku/` 页面路由挂在
   `config` 的 `api/` 前缀下 -> URL 变成 `/api/danmaku/`，而导航写的是 `/danmaku/`
   -> 页面路由移到 apps/web（挂 `/`），fetcher 只留 API
2. **wsgi.py 遗留旧模块引用**：`config/wsgi.py` import 了已删除的
   `apps.fetcher.services.shutdown_cleanup` -> runserver 起不来 -> 删除这两行
