# 实现步骤文档

本目录记录弹幕分析系统的每一步实现。**每完成一个功能步骤，新增一份 `A<n>_<功能名>.md`。**

## 文档模板（每份必须包含）

1. **功能需求**：这一步要解决什么问题、交付什么
2. **技术选型**：用什么方案，为什么（含被否掉的方案）
3. **实现思路（算法逻辑总览）**：核心算法的流程总览，先讲"怎么走"再看代码
4. **具体代码实现**：每个关键函数贴真实代码 + 逐步讲解（数据结构、循环怎么走、边界处理）
5. **运行逻辑**：数据怎么流：输入 -> 处理 -> 输出（含入口函数与关键参数）
6. **验证结果**：用什么数据验证、跑出来的结果、边界用例
7. **踩坑记录**：验证中发现的问题与修法（教学重点）
8. **下一步**：与后续步骤的衔接
