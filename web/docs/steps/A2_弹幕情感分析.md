# A2 弹幕情感分析 — 实现步骤

## 1. 功能需求

- 判断每条弹幕的正 / 负 / 中性情感（打分制）
- 四个输出视图：总体占比、时间轴情绪曲线、高能片段情绪、反应词情绪
- 解决"别的视频的情感词"：词表自动扩展（词典层 + 传播层），不用每个视频手写词表

## 2. 技术选型

- **情感词典法**：词根包含匹配 + 否定翻转 + 程度副词加权
  - 为什么选它：可解释（能说出"为什么这条是负面"）、零训练、易迭代；
    弹幕短小口语化，最适合词典法
- 弃用：机器学习/深度学习（需要标注数据，成本高）；
  SnowNLP 等现成库（训练语料是电商评论，对弹幕"苦的"这类词水土不服）
- 未知反应词用**情感传播**（半监督标签传播）：看这个词出现时刻周围弹幕的情绪投票

## 3. 实现思路（算法逻辑总览）

打分三步：
```
① 词根包含匹配（命中正面加分、负面减分）
② 程度副词加权（增强取 max、减弱取 min）
③ 否定翻转（命中"不/没"等就取反）
```

反应词两层判定：
```
① 字面信号：词本身命中词典直接判（"苦的"含"苦" -> 负面）
② 传播信号：词典判不了（"空瓶""三嫂"），看它出现时刻周围
   有情感弹幕的正/负投票（占比>=60%正面 / <=40%负面 / 中间中性）
```

> 第 4 节每个函数都有代码 + 逐步讲解。

## 4. 具体代码实现

### 4.1 score_danmaku —— 单条弹幕打分（核心算法）

```python
def score_danmaku(content, positive=None, negative=None, negators=None, intensifiers=None):
    positive = positive if positive is not None else POSITIVE
    negative = negative if negative is not None else NEGATIVE
    negators = negators if negators is not None else NEGATORS
    intensifiers = intensifiers if intensifiers is not None else INTENSIFIERS

    score = 0.0
    for word, val in positive.items():
        if word in content:
            score += val
    for word, val in negative.items():
        if word in content:
            score -= val
    if score == 0:
        return 0.0

    # ② 程度加权
    weight = 1.0
    for word, val in intensifiers.items():
        if word in content:
            weight = max(weight, val) if val >= 1 else min(weight, val)
    score *= weight

    # ③ 否定翻转（按长度降序匹配，避免"不是"被"不"先抢到）
    neg_found = any(word in content for word in sorted(negators, key=len, reverse=True))
    if neg_found:
        score = -score
    return round(score, 2)
```

**讲解**：
- ① 用 `word in content`（**包含匹配/子串匹配**）遍历词典。为什么不用精确匹配？
  中文情感词是"词根 + 虚词后缀"，一条"苦的"要覆盖"苦/苦了/太苦/真苦"，
  只要词根"苦"命中即可，不用列全所有变形。
- ② 程度加权：增强副词（"太/超/真" >=1）取 `max`（最强），
  减弱副词（"有点/稍微" <1）取 `min`（最弱）。
  **坑**：如果统一用 `max(weight, val)`，"有点"的 0.5 永远被初始 1.0 挡住（见踩坑1）
- ③ 否定翻转：`sorted(negators, key=len, reverse=True)` 先匹配长的（"不是"）
  再匹配短的（"不"），避免"不是苦的"被"不"抢先、逻辑变成"是苦的"
- 手算验证："太苦了" = -1(苦) x 2.0(太) = -2；"不苦" = -1 x (-1) = +1

### 4.2 _label / _overall —— 标签与总体占比

```python
def _label(avg):
    if avg > POS_THRESHOLD:      # POS_THRESHOLD = 0.2
        return "正面"
    if avg < -POS_THRESHOLD:
        return "负面"
    return "中性"

def _overall(scored):
    pos = sum(1 for _, sc, _ in scored if sc > 0)
    neg = sum(1 for _, sc, _ in scored if sc < 0)
    neu = len(scored) - pos - neg
    total = pos + neg
    return {
        "positive": pos, "negative": neg, "neutral": neu,
        "pos_ratio": round(pos / total, 2) if total else 0,
        "label": "正面为主" if pos > neg else ("负面为主" if neg > pos else "正负均衡"),
    }
```

**讲解**：`scored` 是三元组列表 `(秒, 分数, 弹幕内容)`，全程复用不重复打分。
`pos_ratio` 只看有情绪的弹幕（正/负总数），不含中性，因为中性占比大没意义。

### 4.3 _timeline —— 时间轴情绪曲线

```python
def _timeline(scored, window_sec):
    buckets = {}
    for sec, sc, _ in scored:
        buckets.setdefault(sec // window_sec, []).append(sc)
    max_bucket = max(buckets) if buckets else 0

    labels, score, positive, negative = [], [], [], []
    for i in range(max_bucket + 1):
        vals = buckets.get(i, [])
        sent = [v for v in vals if v != 0]      # 只取有情感的
        labels.append(f"{i * window_sec}-{(i + 1) * window_sec}s")
        positive.append(sum(1 for v in vals if v > 0))
        negative.append(sum(1 for v in vals if v < 0))
        if len(sent) >= 3:
            score.append(round(sum(sent) / len(sent), 2))
        else:
            score.append(None)
    return {"labels": labels, "score": score, "positive": positive, "negative": negative}
```

**讲解**：
- 和 A1 一样按 `sec // window_sec` 分桶（窗口与 A1 保持一致）
- 关键：`sent = [v for v in vals if v != 0]` **只取有情感的弹幕**求平均。
  否则 30s 窗口里 20 条中性 + 1 条"666"会被平均成 0.05，曲线全平（见踩坑3）
- 有情感弹幕 < 3 条时均值不稳，`score` 置 `None`（页面不画点）

### 4.4 _segment_sentiment —— 高能片段情绪

```python
def _segment_sentiment(scored, seg, window_sec):
    vals = [sc for sec, sc, _ in scored if seg["start"] <= sec < seg["end"]]
    sent = [v for v in vals if v != 0]
    n = len(vals)
    score = round(sum(sent) / len(sent), 2) if len(sent) >= 3 else None
    return {
        "start": seg["start"], "end": seg["end"], "peak_sec": seg.get("peak_sec"),
        "count": n,
        "positive": sum(1 for v in vals if v > 0),
        "negative": sum(1 for v in vals if v < 0),
        "neutral": n - sum(1 for v in vals if v != 0),
        "score": score,
        "label": _label(score) if score is not None else "中性",
    }
```

**讲解**：`seg` 直接复用 A1 `hot_segments_v2` 的输出（含 start/end/peak_sec），
只做一次列表过滤 `seg["start"] <= sec < seg["end"]` 取窗口内弹幕。
实测 [0-90s]：123 条里 20 正 3 负，有情绪平均 = 0.96 -> **正面爆点**。

### 4.5 _reaction_sentiment —— 反应词两层判定（A2 核心）

```python
def _reaction_sentiment(scored, reaction_word, window_sec):
    word = reaction_word["word"]
    radius = window_sec // 2

    occur_times = []      # 含该词的弹幕时间点
    ctx = []              # 不含该词且【有情感】的弹幕 (sec, score)
    for sec, sc, content in scored:
        if word in content:
            occur_times.append(sec)
        elif sc != 0:
            ctx.append((sec, sc))

    # ① 字面信号：词本身命中词典（"苦的"含"苦"）
    literal = score_danmaku(word)
    if literal != 0:
        return {"word": word, "count": reaction_word["count"], "method": "词典",
                "literal_score": literal, "score": literal, "label": _label(literal)}

    # ② 传播信号：词典判不了，看它出现时刻周围有情感弹幕的正/负投票
    votes = [sc for sec, sc in ctx if any(abs(sec - t) <= radius for t in occur_times)]
    pos = sum(1 for v in votes if v > 0)
    neg = sum(1 for v in votes if v < 0)
    n = len(votes)
    if n >= 3:
        ratio = pos / (pos + neg)
        label = "正面" if ratio >= 0.6 else ("负面" if ratio <= 0.4 else "中性")
    else:
        label = "中性"
    avg = sum(votes) / n if n else 0.0
    return {"word": word, "count": reaction_word["count"], "method": "传播",
            "positive_votes": pos, "negative_votes": neg, "context_samples": n,
            "score": round(avg, 2) if n else None, "label": label}
```

**讲解**：
- 遍历 scored 一遍同时拿到两类数据：
  - `occur_times`：含该词的弹幕时间点（如"苦的"出现的那 20 个时刻）
  - `ctx`：不含该词且**有情感**的弹幕（中性弹幕直接丢掉，见踩坑3）
- ① 字面信号：`score_danmaku(word)` 给词本身打分——"苦的"含"苦" -> -1 -> 负面。
  又准又可解释，优先级最高
- ② 传播信号：对每个出现时刻 t，取半径 `window_sec//2` 秒内的 ctx 弹幕分数投票。
  **标签按投票占比判**（>=60% 正面 / <=40% 负面 / 中间中性）而不是按均值——
  均值会被高分弹幕带偏（"空瓶"29:25 投票均衡却算出 0.35 的"正面"，见踩坑5）
- `context_samples` 记录投票样本数，样本太少（<3）不敢下结论 -> 中性

### 4.6 sentiment_analyze —— 组装

```python
def sentiment_analyze(records, window_sec=30, segments=None, reaction_words=None):
    scored = []
    for r in records:
        sec = int((r.get("progress_ms") or 0) / 1000)
        content = (r.get("content") or "").strip()
        if content:
            scored.append((sec, score_danmaku(content), content))

    return {
        "overall": _overall(scored),
        "timeline": _timeline(scored, window_sec),
        "by_segment": [_segment_sentiment(scored, s, window_sec) for s in (segments or [])],
        "reaction_sentiment": [_reaction_sentiment(scored, w, window_sec)
                               for w in (reaction_words or [])],
    }
```

**讲解**：先统一把每条弹幕打分一次，生成 `scored` 列表，四个视图共用，
避免重复调用 score_danmaku。`segments`/`reaction_words` 是 A1 算好的结果，
由 `analyze_danmaku` 传入。

### 4.7 emotion_dict.py —— 词典结构

```python
POSITIVE = {"666": 1, "6": 1, "yyds": 2, "泪目": 1, "破防": 1, "笑": 1, "香": 1, ...}
NEGATIVE = {"苦": 1, "寄": 1, "烂": 1, "麻了": 1, "血压": 1, "难": 1, ...}
NEGATORS = ["不是", "没有", "不太", "不", "没", "非", "未", "甭", "休", "莫"]
INTENSIFIERS = {"超级": 2.0, "太": 2.0, "真": 2.0, "很": 1.5, "有点": 0.5, ...}
```

**讲解**：词典是"数据 + 规则"分离的体现。词根别太短（"神"会命中"神经"、
"别"会命中"特别"），否定词不放"无"（会误伤"无敌"）。加新词只需改这个文件。

## 5. 运行逻辑

```
analyze_danmaku(bvid)
   -> records / duration_sec / window_sec
   -> segments_v2 = hot_segments_v2(records, duration_sec)      # A1
   -> reaction_words = auto_reaction_words(records, duration_sec) # A1
   -> sentiment = sentiment_analyze(records, window_sec,
                                    segments=segments_v2,
                                    reaction_words=reaction_words)
   -> result["sentiment"] 写 data/out/danmaku/{bvid}.json
```

关键参数：`POS_THRESHOLD=0.2`（标签阈值）、传播投票占比 0.6/0.4、样本下限 3

## 6. 验证结果（BV15BuR6MEeR）

- 总体：正 156 / 负 81 / 中性 1131（pos_ratio 0.66，正面为主）
- `by_segment`：[0-90s] 20正3负 score=0.96 -> **正面爆点**
- `reaction_sentiment`：
  - 苦的 [词典] 字面-1 -> **负面**（本视频核心反应词，判对）
  - 666 [词典] +2 -> 正面；6000+ [词典] +1 -> 正面
  - 收了收了 [传播] 45:12 -> 正面；占领空屏 [传播] 45:14 -> 正面
  - 空瓶 [传播] 29:25 -> **中性**（投票均衡，诚实判中性）
- 时间轴：结尾 1500-1530s score=-1.0（"苦的"集中，负面）
- 单元测试 15 条用例全部通过

## 7. 踩坑记录

1. **减弱副词失效**：`max(1.0, 0.5)` 永远取不到 0.5，"有点苦"没变弱
   -> 增强副词取 max、减弱副词取 min
2. **词典重叠双计**："真香"同时命中"真香"+"香" -> 删复合词，只留词根"香"
3. **中性弹幕稀释（最关键）**：1131/1369 条弹幕无情感词，直接平均全被拉到 0 附近
   -> 所有均值只统计有情感的弹幕
4. **传播法被多话题淹没**："苦的"周围弹幕太密，光靠传播判成中性
   -> 改成两层判定：字面优先 + 传播兜底
5. **投票 vs 均值**：空瓶 29:25 被高分正面弹幕拉成"正面"
   -> 传播法标签改为按投票占比判定
