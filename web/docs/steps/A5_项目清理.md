# A5 项目清理 — 实现步骤

> 说明：原规划的热门榜页（/danmaku/hot/）已按用户要求**移除**（页面/命令/任务/路由/导航全部删除）。
> 本项目当前只做"按 BV 号爬取弹幕并分析"一条功能线。

## 1. 功能需求

- 清理旧"观看历史画像"项目遗留文件，把文档/依赖改成弹幕分析系统
- 移除热门榜功能（页面 /danmaku/hot/、命令 bili_fetch_hot_danmaku、任务 tasks.py）
- 移除无引用的旧模块与配置（加密 / VM 数仓 / Celery）
