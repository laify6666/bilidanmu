# A3 关键词分析（jieba） — 实现步骤

## 1. 功能需求

- 从弹幕里提取高频**关键词**（词，不是整句），回答"观众在聊什么"
- 两个输出：
  - 全局关键词 TopN：这个视频弹幕的主题词（死因、帝王、鲨鱼、蜥蜴…）
  - 按高能片段的关键词：每个高潮在聊什么（喂 A1 的 segments_v2）
- 和 A1 反应词分工：反应词 = 观众刷的短句/梗（666、苦的）；关键词 = 观众聊的主题词

## 2. 技术选型

- **jieba**：最流行的中文分词库，纯 Python、开箱即用
  - 中文没有空格，必须分词；正则硬拆不可行
  - 弃用：hanlp / thulac（模型大、依赖重）
- **停用词表**：去掉"的、了、我、你、这么"等高频虚词——词频统计最关键的一步，
  不过滤的话 Top 全是虚词
- 安装：`pip install jieba`（官方源超时，实际用清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）

## 3. 实现思路（算法逻辑总览）

```
每条弹幕 -> jieba.cut() 分词 -> 逐词过滤（停用词/单字/纯数字/语气词/纯标点）
   -> 统一转小写（OK/ok 合并） -> Counter 词频 -> TopN
```

过滤规则（`_valid`，按顺序）：
1. 长度 < 2：单字大多是语气词/噪声
2. 命中停用词表
3. 命中重复字符语气词正则 `(哈|啊|哦|嗯|嘿|嘻|哎|哟)\1+`（哈哈哈/啊啊啊）
4. 纯数字（666 交给 A1 反应词，不算主题词）
5. 不含汉字/字母数字（纯标点/表情）

## 4. 具体代码实现

### 4.1 停用词表 + 语气词正则

```python
STOPWORDS = set("""
的 了 吗 啊 吧 呢 呀 嘛 哦 嗯 嘿 哟 哈
我 你 他 她 它 我们 你们 他们 大家 自己
这 那 这个 那个 这些 那些 这里 那里 什么 怎么 为什么 为啥 谁 哪 几 多少
是 在 有 和 与 或 就 都 也 还 又 再 很 太 真 好 不 没 别 一 一个 一下
不是 没有 这么 那么 出来 看见 知道 真的 感觉 觉得 有点 已经 然后 但是 因为 所以
""".split())

LAUGH_PAT = re.compile(r"^([哈啊哦嗯嘿嘻哎哟])\1+$")
```

**讲解**：
- 停用词匹配的是 **jieba 切出来的完整词**，所以"好"不会误伤"好吃"（jieba 把"好吃"切成一个词）
- `\1` 反向引用：`([哈啊哦…])\1+` 表示"同一个字符重复 1 次以上"，
  匹配 哈哈哈 / 啊啊啊 / 嘿嘿嘿，但不匹配单个"哈"

### 4.2 _valid / _tokenize —— 过滤 + 分词

```python
def _valid(word):
    if not word or len(word) < 2:
        return False
    if word in STOPWORDS:
        return False
    if LAUGH_PAT.match(word):
        return False
    if all(ch in "0123456789" for ch in word):
        return False
    if not any("\u4e00" <= ch <= "\u9fff" or ch.isalnum() for ch in word):
        return False
    return True


def _tokenize(content):
    return [w.lower() for w in jieba.cut(content) if _valid(w.lower())]
```

**讲解**：
- `jieba.cut(content)` 返回生成器，逐词判断
- **统一转小写**：`OK` 和 `ok` 在中文弹幕里是同一个词，`w.lower()` 后合并计数
- `_valid` 收的是小写形式，停用词表/正则按小写匹配

### 4.3 extract_keywords —— 全局关键词

```python
def extract_keywords(records, top_n=20):
    counter = Counter()
    for r in records:
        content = (r.get("content") or "").strip()
        if not content:
            continue
        for w in _tokenize(content):
            counter[w] += 1
    return [{"word": w, "count": c} for w, c in counter.most_common(top_n)]
```

**讲解**：遍历弹幕 -> 分词 -> Counter 累加 -> `most_common(top_n)` 直接取前 N。
`Counter.most_common` 是按次数降序的内置方法，不需要手写排序。

### 4.4 keywords_by_segment —— 分片段关键词

```python
def keywords_by_segment(records, segments, top_n=10):
    tokenized = []
    for r in records:
        content = (r.get("content") or "").strip()
        if not content:
            continue
        sec = int((r.get("progress_ms") or 0) / 1000)
        tokenized.append((sec, _tokenize(content)))

    result = []
    for seg in segments:
        counter = Counter()
        for sec, words in tokenized:
            if seg["start"] <= sec < seg["end"]:
                for w in words:
                    counter[w] += 1
        result.append({
            "start": seg["start"], "end": seg["end"],
            "words": [{"word": w, "count": c} for w, c in counter.most_common(top_n)],
        })
    return result
```

**讲解**：
- **先全量分词一次**存成 `(秒, [词])`，再按片段过滤——避免每个片段都重新分词一遍
  （分段多时这是 O(段数×n) vs O(n) 的差别）
- 片段时间范围用 `seg["start"] <= sec < seg["end"]`（左闭右开，和 A1 一致）

## 5. 运行逻辑

```
analyze_danmaku(bvid)
   -> records / segments_v2（A1）
   -> keywords = {
        "global": extract_keywords(records),
        "by_segment": keywords_by_segment(records, segments_v2),
      }
   -> result["keywords"] 写 data/out/danmaku/{bvid}.json
```

关键参数：`top_n=20`（全局）、`top_n=10`（每片段）

## 7. 踩坑记录

1. **大小写没归一**：`OK`(56) 和 `ok`(30) 是两个词 -> 统一 `w.lower()` 合并
2. **停用词表漏词**：`不是`、`没有`、`这么` 混进 Top -> 扩充停用词表
3. **语气词当关键词**：`哈哈哈`(42)、`啊啊啊`(27) 是情绪不是主题
   -> 加重复字符语气词正则过滤
